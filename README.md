# API de Cadastro de Pessoas

API desenvolvida em Python utilizando FastAPI.

## Funcionalidades

- Cadastrar pessoas
- Listar pessoas
- Buscar pessoa por CPF
- Remover pessoa
- Validação de CPF duplicado

## Campos

- Nome
- CPF
- Data de nascimento
- Sexo
